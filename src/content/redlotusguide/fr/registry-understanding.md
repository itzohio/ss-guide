# Comprendre le registre Windows

Le registre, c'est une base de données hiérarchique intégrée à Windows. Il stocke les réglages bas niveau de l'OS, du matériel et de beaucoup d'applications (système comme tierces). Les développeurs y rangent des données sous forme de clés et de sous-clés, qui définissent le comportement des logiciels et du matériel.

C'est le hub de configuration central. Ce qu'on y change peut avoir un gros impact sur le comportement, les performances et les fonctions du système. Les applications légitimes (services, optimiseurs) comme les logiciels malveillants peuvent lire et modifier le registre.
