# Les techniques de nettoyage d'artefacts

Une grosse catégorie de bypass consiste à supprimer ou effacer directement les données des artefacts Windows qui loggent l'activité. Le but est simple : virer les traces compromettantes avant ou pendant le screenshare pour avoir l'air clean. Savoir comment ces artefacts sont nettoyés, et surtout comment ce nettoyage se repère, est indispensable.
