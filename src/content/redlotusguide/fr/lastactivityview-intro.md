# LastActivityView : l'agrégation d'artefacts

LastActivityView est un autre outil gratuit de Nirsoft, très utile. Sa fonction : rassembler les infos d'activité utilisateur venant de plusieurs artefacts Windows et les afficher dans une seule interface triée par date. Au lieu de vérifier Prefetch, puis des clés de registre, puis les journaux d'événements séparément, LastActivityView regroupe tout ce petit monde dans une vue unique.
