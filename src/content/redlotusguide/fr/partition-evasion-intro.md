# Manipuler les partitions de disque pour se cacher

Cette technique joue sur la création puis la suppression d'une partition séparée pour contourner la journalisation classique du système de fichiers et cacher l'activité ou les fichiers aux analyses centrées sur le disque système (souvent C:).
