# Dissimulation et obfuscation

Le but de base de beaucoup de bypass, c'est simplement de cacher des fichiers ou une activité au SSer. Si le cheat ne se trouve pas ou ne s'identifie pas, il ne se prouve pas. D'où tout un tas de méthodes pour faire ressembler un fichier illicite à un fichier normal, le faire disparaître des vues classiques, ou rendre son code illisible.
