# Les techniques de contournement du Planificateur de tâches

Le Planificateur de tâches de Windows est un composant légitime et puissant : il permet de lancer des programmes ou des scripts à des heures précises ou en réaction à des événements système (démarrage, connexion, inactivité). Les attaquants et les bypassers l'exploitent pour la persistance (leur code tourne tout seul) et pour l'évasion (exécuter du code hors de l'interaction directe de l'utilisateur).
