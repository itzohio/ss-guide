# Les langages de script pour l'évasion

Les scripts sont un outil de choix pour contourner un screenshare : ils sont légers, faciles à modifier et s'exécutent avec des interpréteurs déjà présents sur le système. Cette partie détaille les mécanismes utilisés et les traces qu'ils laissent.
