# Malware sans fichier et binaires vivant de la terre (LOLBins)

Les attaquants et les bypassers utilisent souvent les langages de script déjà présents sur Windows plutôt que des exécutables compilés classiques (`.exe`). Cette approche "Living-off-the-Land" exploite des interpréteurs légitimes déjà installés pour exécuter du code malveillant, ce qui rend la détection plus dure pour les solutions de sécurité qui ne cherchent que des exe inconnus. Les langages les plus détournés : PowerShell (`.ps1`), Batch (`.bat`), VBScript (`.vbs`), et plus rarement Python (`.py`), AutoIt (`.au3`) ou les HTML Applications (`.hta`).
