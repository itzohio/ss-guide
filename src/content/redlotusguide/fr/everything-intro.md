# Search Everything : la recherche rapide dans les fichiers

Search Everything, de voidtools, est un utilitaire de recherche ultra rapide et léger pour Windows. Contrairement à la recherche Windows intégrée, qui indexe lentement le contenu et les métadonnées, Everything indexe surtout les noms de fichiers et dossiers et les chemins sur les volumes NTFS, quasiment instantanément. C'est donc un outil indispensable en screenshare pour retrouver un fichier n'importe où sur le système.
