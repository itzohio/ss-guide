# Process Hacker / System Informer : présentation et configuration

System Informer, c'est le successeur toujours maintenu du populaire Process Hacker 2 (arrêté). C'est un utilitaire système gratuit, open source et très puissant, indispensable pour un screenshare manuel efficace. Il fait beaucoup de choses (monitoring, debug), mais ce qui nous intéresse surtout, c'est sa capacité à inspecter en profondeur les processus, les services, les connexions réseau et, surtout, leur mémoire, pour repérer un logiciel non autorisé ou une manipulation.
