# Le mécanisme de l'évasion

- **Living-off-the-Land :** les scripts s'appuient sur des interpréteurs intégrés à Windows (`powershell.exe`, `cmd.exe`, `cscript.exe`, `wscript.exe`, `mshta.exe`) ou couramment installés (`python.exe`, `AutoIt3.exe`). Comme ces interpréteurs sont légitimes, leur exécution est moins susceptible de déclencher une alerte qu'un exe totalement inconnu.
- **Exécution sans fichier (PowerShell) :** PowerShell est particulièrement pratique parce qu'il permet d'exécuter du code directement en mémoire, sans écrire de script sur le disque. Les commandes peuvent être téléchargées et lancées à la volée, ou passées encodées en ligne de commande, ce qui limite les artefacts sur le disque.
- **Obfuscation :** un script se brouille facilement (encodage Base64, substitution de caractères, découpage en petits morceaux), ce qui complique l'analyse statique.
- **Automatisation :** les scripts sont très forts pour enchaîner des actions : désactiver des services de sécurité, supprimer des logs ou des fichiers (Prefetch, clés de registre, historique du navigateur), modifier des réglages système, télécharger et exécuter un payload secondaire.
- **Interaction avec les composants système :** un script peut appeler directement les API Windows, WMI, les objets COM et le .NET, ce qui ouvre la porte à des opérations complexes : injection de processus, manipulation du registre, communication réseau, persistance (tâches planifiées, entrées de démarrage).
- **Exploitation des HTA :** les HTML Applications (`.hta`) exécutent des scripts embarqués (VBScript, JScript) avec plus de privilèges qu'une page web, via `mshta.exe`. Ça contourne le bac à sable du navigateur et permet d'exécuter du code quand l'utilisateur ouvre le fichier.
- **AutoIt pour l'automatisation :** AutoIt est un langage de script légitime pour automatiser l'interface Windows. Les attaquants le détournent pour simuler des clics et des frappes (macros complexes, autoclickers) ou automatiser des tâches malveillantes. Les scripts AutoIt compilés (`.exe`) sont parfois plus durs à analyser que d'autres types de scripts.
