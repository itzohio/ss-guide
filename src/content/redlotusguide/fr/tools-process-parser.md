# process-parser

Description : un outil centré sur le parsing et l'analyse des informations liées aux processus système, qui examine probablement les processus en cours ou des données historiques issues d'artefacts.

Usage : peut servir à examiner les détails des processus en cours ou passés, ce qui aide à identifier des processus suspects ou à analyser leurs relations. (Plus de détails dans le README de l'outil.)
