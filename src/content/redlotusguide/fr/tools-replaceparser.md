# Replaceparser

Description : un parseur simple et autonome, conçu pour détecter les remplacements de fichier en analysant les entrées du journal USN. Créé au départ pour des tests, il s'utilise aussi de façon indépendante.

Fonctions :

- Se concentre uniquement sur le parsing et l'identification des opérations de remplacement de fichier dans le journal USN.
- Peut s'intégrer comme bibliothèque dans d'autres outils maison.

Note : l'exécutable fourni dans les releases peut être plus ancien que le code source disponible sur GitHub.

Usage : un outil dédié pour vérifier rapidement si des fichiers précis ont subi un remplacement, en complément d'une analyse plus large du journal.

Lien : `https://github.com/spokwn/Replaceparser`
